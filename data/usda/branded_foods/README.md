# USDA Branded Foods Dataset

Branded food items are integrated on-demand via the USDA FoodData Central REST API (`https://api.nal.usda.gov/fdc/v1/`) and cached dynamically in NutriScan AI's SQLite/PostgreSQL store.
Full bulk branded CSVs (>4 GB uncompressed) can be ingested directly into Phase 10 feature storage if required.
